Repositórios

A extensão lê o .git do repositório aberto no VS Code e só liga se ele estiver aqui.

    Como usar neste projeto

    1. 1
      Instale a extensão ShielDepy no VS Code

      Ela aparece na barra lateral com o escudo verde.

    2. 2
      Entre com a sua conta

      Clique em "Entrar" na extensão e confirme no navegador.

    3. 3
      Abra um dos repositórios acima

      A extensão confere o remote do .git e libera sozinha. O uso aparece aqui na hora.
